# Reflexión sobre el Trabajo Práctico

## a. ¿Qué nota creemos que deberíamos sacar en el TP? ¿Por qué?

Creemos que el trabajo merece un **8/10**. Pudimos completar todas las funcionalidades que pedía la consigna y el sistema funciona correctamente en los casos previstos. Además, tratamos de mantener el código ordenado y de aplicar los conceptos vistos durante la cursada. Si bien estamos conformes con el resultado, sabemos que hay aspectos que podrían mejorarse y que siempre hay margen para seguir optimizando la solución.

## b. ¿Qué cosas creemos que podrían mejorarse?

Creemos que se podría mejorar la organización de algunas partes del código para hacerlo más fácil de mantener y entender. También sería útil agregar más validaciones y realizar más pruebas para contemplar distintos escenarios. Por otro lado, con más tiempo se podrían incorporar algunas mejoras o funcionalidades adicionales que no eran obligatorias pero que aportarían valor al proyecto.

## c. ¿Qué nos resultó más complicado?

Lo más complicado fue adaptarnos a las herramientas y conceptos nuevos que tuvimos que utilizar durante el desarrollo. También llevó tiempo coordinar el trabajo entre los integrantes del grupo y unificar las distintas partes del proyecto para que todo funcionara correctamente. Resolver errores y encontrar la causa de algunos problemas fue una de las tareas que más tiempo nos demandó, pero también fue una de las partes donde más aprendimos.
